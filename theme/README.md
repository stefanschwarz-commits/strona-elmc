# Motyw ELMC 2027

Docelowo tu trafi kod motywu WordPress dla `dev.ekmp.pl` (ELMC 2027).

Zawartość tego katalogu jest automatycznie wdrażana przez GitHub Actions
(`.github/workflows/deploy.yml`) na serwer, do katalogu
`public_html/dev.ekmp.pl/wp-content/themes/elmc2027`, przy każdym pushu
do gałęzi `main`.
